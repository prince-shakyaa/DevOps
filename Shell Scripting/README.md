# Shell Scripting Basics

Exploring automation through bash scripting.

## The `sysinfo.sh` Script
This practical script demonstrates several key shell scripting concepts:
- **Variables**: Storing and referencing data.
- **User Input**: Reading data from the user interactively.
- **File Operations**: Utilizing commands like `mkdir` and `touch` within the script.
- **Redirection**: Saving output to a file instead of the terminal (`>`).

### Execution
Scripts must be made executable using `chmod +x sysinfo.sh` before they can be run directly using `./sysinfo.sh`.
