# Introduction to Docker

Practical exercises covering basic container deployment using popular technologies.

## Container Examples
1. **Node.js**: A basic web server using the official Node image.
2. **Python**: Running a simple script via the Python base image.
3. **Java**: Compiling and running Java applications inside a container.
4. **Apache/Nginx**: Serving static HTML content using standard web server images.
5. **React**: A frontend application built and served via a containerized setup.

### Basic Commands
- `docker pull <image>`: Download an image.
- `docker run -d -p host:container <image>`: Run in detached mode with port mapping.
- `docker ps`: List running containers.
- `docker stop <id>`: Stop a container.
